# MCP Data Ops Agent

An MCP-style autonomous data operations agent built with Python, SQL, and LLM-based reasoning.

## Project Goal
This project simulates a data operations agent that can:
- inspect pipeline health
- run checks on operational data
- detect anomalies
- recommend or trigger corrective actions

## Tech Stack
- Python
- SQL / SQLite
- VS Code
- GitHub
- OpenAI API
- MCP-style tool execution
